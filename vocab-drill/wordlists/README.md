# 预置词单使用说明（给 agent 读）

`wordlists/` 下是**词头清单**，不是成品词库——每个文件只有词头（可选：中文锚点），
词卡（释义/同反义/quirky 例句）走正常 CARDS 流水线现生成。这样词单永远轻量，
例句质量跟着模型升级，不像静态词库会过时。

## 用法

用户说「我要考雅思/托福/SAT/GRE」或「想提高日常/职场词汇」但没带材料时：

1. 读对应词单文件，展示给用户看前 10 个词 + 总数，问「从哪一段开始」（一段 10-15 个）
2. 用户选段后，走正常流程：CARDS 生成词卡 → `--add` + `--card` → STORY → QUIZ
3. **不要一次倒入全部**——一次 session 5-15 个词（SKILL.md 主流程规则不变）
4. 词单只是「食材清单」，进了 `--add` 就纳入 SM2 调度，跟自建词完全同一套

## 分段策略

每词单按难度自然排序（前易后难）。用户没主意时默认从第 1 段开始；
已学过的词 `--add` 会自动跳过（词库去重），所以重复导入无害。

## 文件清单

| 文件 | 定位 | 规模 |
|---|---|---|
| `ielts-core.md` | 雅思核心（Task 1/2 分话题 + 听力同义替换）| ~140 词 |
| `toefl-academic.md` | 托福学术（按讲座学科场景分组）| ~130 词 |
| `sat-reading.md` | SAT 阅读（文学/历史/社科 + 熟词僻义）| ~110 词 |
| `gre-advanced.md` | GRE 进阶（填空核心难词 + 形近易混组）| ~120 词 |
| `daily-upgrade.md` | 日常升级（母语者常用、学习者少用的好词）| ~110 词 |

**边界声明**：词单是「入门精选 + 考试季日常量」，不是完整考试词库
（IELTS/GRE 完整词表在 3000 词量级）。用户系统备考时，引导他们导入自己的
词表/讲义/真题文章走 EXTRACT 流程——那才是 skill 的主战场。
